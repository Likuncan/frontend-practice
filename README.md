# frontend-practice 前端学习练习仓库

## 简介

这是我学习前端开发的练习仓库，用 HTML 和 Git 记录从零开始的学习过程。目前包含两个练习项目：个人主页，以及介绍家乡宜宾的主题页面。

## 目录结构

```
git-practice/
├── index.html          # 练习1：个人主页（自我介绍、爱好、常用链接）
├── images/             # 个人主页使用的图片
│   ├── me.jpg
│   └── photo.jpg
├── theme-page/         # 练习2：主题页面——我的家乡宜宾
│   ├── index.html      # 宜宾的美食与风景介绍
│   └── images/         # 主题页配图（风景照、美食照）
└── .gitignore          # Git 忽略规则（系统文件、编辑器配置）
```

## 各页面说明

| 页面 | 路径 | 练习内容 |
|------|------|----------|
| 个人主页 | `index.html` | 标题、段落、列表、链接、图片等基础标签 |
| 宜宾主题页 | `theme-page/index.html` | 完整文档结构、多板块排版、相对路径引用图片 |

## 学习笔记

- 使用 `.gitignore` 忽略系统文件和编辑器配置，保持仓库干净
- 推送前先 `git pull --rebase`，避免与远程提交冲突
